# Security Policy

## Supported versions

Only the latest released version of app-router receives fixes. Please update to the newest release before reporting an issue.

## Reporting a vulnerability

Please report security issues privately rather than opening a public issue:

- Use GitHub's **"Report a vulnerability"** button (Security tab → Privately report a vulnerability): <https://github.com/jsglazer/app-router/security/advisories/new>
- or open a regular issue **without** sensitive details and ask for a private channel.

Please include reproduction steps and the version you are running (see the app's About window). We aim to acknowledge reports within 14 days and to release a fix in a subsequent version.

## Scope

app-router is a macOS application. Report anything that could let untrusted input (files it opens, data it receives) execute code, escape the app's sandbox or entitlements, or expose or corrupt your data.
